Privacy Policy

Effective date: May 10, 2025  ·  Version 1.0
// PLAIN ENGLISH SUMMARY

BugReplay Recorder captures browser activity only while you actively press Record, stores everything exclusively on your own device, and transmits nothing to any server — ever. The exported .replay file is a plain JSON file that you control and share manually. We collect no analytics, no telemetry, and no account data.

01

Who we are

BugReplay Recorder is an independently developed Chrome extension. References to "we", "us", or "our" in this policy refer to the extension developer. This extension is not affiliated with Google, Anthropic, or any other company.

For contact details, see Section 9.

02

What data the extension accesses

When you press Start Recording, the extension captures the following from the active browser tab:

Data type What is captured Sent to server?
Mouse clicks Click coordinates (x, y) and the CSS selector of the clicked element NEVER
Keyboard input Values typed into form fields (passwords auto-redacted); special key presses (Enter, Escape, Tab, arrows) NEVER
DOM changes Structural mutations to the page (elements added, removed, or modified) NEVER
Network requests HTTP method, URL, and status code of XHR and fetch calls made by the page. Request/response bodies are not captured. NEVER
Console output Messages logged via console.log, console.warn, and console.error NEVER
JavaScript errors Uncaught exceptions and unhandled promise rejections NEVER
Page metadata Page title, URL, and browser user-agent string at the time of recording NEVER
DOM snapshot A one-time snapshot of the page's HTML at the moment recording starts (used to reconstruct the visual baseline for replay) NEVER

No data is captured while recording is stopped. The extension is entirely dormant until you explicitly press Start Recording.

03

Automatic password and sensitive field redaction

Before any keystroke data is written to the recording, the extension checks the input element's name, id, autocomplete, and type attributes against a list of sensitive patterns:

password  |  passwd  |  pwd  |  secret  |  token  |  auth  |  card  |  cvv  |  ssn  |  pin

Any field matching this list — and all fields of type password — are stored as the literal string [REDACTED]. The actual value is never written to memory or disk.

Important limitation: This redaction is best-effort. Fields that do not use standard naming conventions may not be detected. Users should review exported .replay files before sharing them if the recorded session involved sensitive information.

04

How and where data is stored

All captured data lives exclusively on your device:

Storage location Contents Cleared when
Page memory (RAM) Live event buffer while recording is active You stop recording or close the tab
chrome.storage.local Recording state flag and the most recent session payload (for popup UI state) You uninstall the extension, or manually via Chrome settings
Your Downloads folder The exported .replay file — a plain JSON text file You delete it

No cloud storage, no remote database, no third-party service is involved at any stage.

05

Data sharing and transmission

We do not transmit any data anywhere. The extension makes zero outbound network requests. It does not contact our servers (we have none), analytics services, error tracking services, or any third party.

The .replay file you export is shared manually by you — by attaching it to a GitHub issue, Slack message, email, or any other channel you choose. You are fully in control of who receives it and when.

06

Permissions and why we need them

Permission Why it is required
activeTab Access the currently active tab to inject the recording script when you press Start
scripting Inject the content script (content.js) into the page programmatically on demand
storage Persist recording state in chrome.storage.local so the popup shows the correct state if closed and reopened
downloads Trigger the file download of the .replay file to your Downloads folder
<all_urls> (host permission) Allow recording on any website you choose. The extension does not access any site unless you explicitly press Start Recording on that tab.
07

Children's privacy

BugReplay Recorder is a developer tool intended for adults. It is not directed at children under 13 (or the applicable age of digital consent in your jurisdiction). We do not knowingly collect any information from children.

08

Because we collect no personal data and have no user accounts, we have no mechanism to notify users directly of changes. We recommend bookmarking this page if you wish to monitor updates.
